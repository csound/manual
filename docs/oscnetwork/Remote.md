# **Remote Opcodes**

The Remote opcodes enable transmission of score or MIDI events through a network, so remote instances (or a different local instance) can process them. The following opcodes are available:


* [insglobal](../../opcodes/insglobal) - Used to implement a remote orchestra.
* [insremot](../../opcodes/insremot) - Used to implement a remote orchestra.
* [midiglobal](../../opcodes/midglobal) - Used to implement a remote MIDI orchestra.
* [midiremot](../../opcodes/midremot) - Used to implement a remote MIDI orchestra.
* [remoteport](../../opcodes/remoteport) - Defines the port for use with the remote system.
