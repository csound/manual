# **Other Csound Utilities (CS, CSB64ENC, DNOISE, ENVEXT, EXTRACTOR, MAKECSD, MIXER, SCALE)**

The following miscellaneous utilities are available:

* [CS](../cs): Starts Csound with a set of options that can be controlled by environment variables, and input and output files determined by the specified filename stem.
* [CSB64ENC](../csb64enc): Converts a binary file to a Base64 enconded text file.
* [DNOISE](../dnoise): Reduces noise in a file.
* [ENVEXT](../envext): Extract the envelope of a file to a text list.
* [EXTRACTOR](../extractor): Extract a section of audio from an audio file.
* [MAKECSD](../makecsd): Creates a CSD file from the specified input files.
* [MIXER](../mixer): Mixes together a number of soundfiles.
* [SCALE](../scaleutility): Scale the amplitude of a sound file.
