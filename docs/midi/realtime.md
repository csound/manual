# **System Realtime Messages**

[midicontinue](../opcodes/midicontinue.md) reports incoming Continue messages for resuming transport.
[midiclockin](../opcodes/midiclockin.md) reports incoming clock pulses for triggering and sequencing.
`midiclockfreq` measures incoming clock frequency. See [midiclockfreq](../opcodes/midiclockfreq.md) for tempo conversion and an example.

Opcodes for System Realtime MIDI messages are: [mclock](../opcodes/mclock.md) and [mrtmsg](../opcodes/mrtmsg.md).

Use [midistart](../opcodes/midistart.md) to detect incoming MIDI Start messages.
