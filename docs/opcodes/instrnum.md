# instrnum
Returns an instrument number from a name or definition.

`instrnum` is another name for [nstrnum](nstrnum.md).

## Syntax

=== "Modern"
    ``` csound-orc
    iNumber = instrnum(Sname)
    iNumber = instrnum(definition[, iOffset])
    ```

=== "Classic"
    ``` csound-orc
    iNumber instrnum Sname
    iNumber instrnum definition[, iOffset]
    ```

See [nstrnum](nstrnum.md) for the arguments, examples and credits.

New in Csound 7.
