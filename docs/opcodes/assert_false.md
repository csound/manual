# assert_false
Checks that a condition is false when testing is enabled.

See [assert](assert.md) for the shared reference, testing option, accepted inputs and example.

## Syntax

=== "Modern"
    ``` csound-orc
    assert_false(condition)
    ```

=== "Classic"
    ``` csound-orc
    assert_false condition
    ```
