# assert_true
Checks that a condition is true when testing is enabled.

See [assert](assert.md) for the shared reference, testing option, accepted inputs and example.

## Syntax

=== "Modern"
    ``` csound-orc
    assert_true(condition)
    ```

=== "Classic"
    ``` csound-orc
    assert_true condition
    ```
