# instrstr
Returns an instrument name from its number.

`instrstr` is another name for [nstrstr](nstrstr.md).

## Syntax

=== "Modern"
    ``` csound-orc
    Sname = instrstr(iNumber)
    Sname = instrstr(kNumber)
    ```

=== "Classic"
    ``` csound-orc
    Sname instrstr iNumber
    Sname instrstr kNumber
    ```

See [nstrstr](nstrstr.md) for the arguments, examples and credits.

New in Csound 7.
