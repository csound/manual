# print_type
Prints the type of a variable or expression.

This is the older spelling of [printtype](printtype.md). See that page for the shared reference and example. Use `printtype` in new Csound 7 code.

## Syntax

=== "Modern"
    ``` csound-orc
    print_type(xarg)
    ```

=== "Classic"
    ``` csound-orc
    print_type xarg
    ```
